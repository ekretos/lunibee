# Lunibee 1.0.0 — stable

**Theme:** the stability promise in ROADMAP.md. 1.0.0 is the last 0.9.x release
candidate with its version changed; no feature lands here.

**Target:** 1.0.0, then 1.x minors (features) and patches (fixes). Branch: `dev`, tagged from it.

---

## Step 1 — Exit criteria (ROADMAP.md, "1.0.0 exit criteria")

1. [ ] 0.5.0 through 0.9.0 released; voice shipped or marked `@experimental` where it is not covered
   by the smoke test.
2. [ ] No open P0 or P1 findings; P2/P3 fixed or tracked.
3. [ ] Every public export marked and covered by the API audit; no `Record<string, unknown>` in
   public message or interaction option types.
4. [ ] Coverage gate at or above lines 90%, functions 50% per file.
5. [ ] Docs build, generated API docs and every example run in CI.
6. [ ] Upgrade guide to 1.0 published; semver and deprecation policy published.
7. [ ] A production bot has run the release candidate for two weeks without a Lunibee-caused incident.
8. [ ] `check:leaks` and the 24-hour soak test (0.8.0) pass on the candidate.

## Step 2 — Release

1. [ ] Versions to 1.0.0; `AGENT.md` release target, changelog and package READMEs updated.
2. [ ] Docs: archive 0.9.x in the version picker; 1.0 becomes the default.
3. [ ] Tag `1.0.0`, `publish:all`, announcement.

## After 1.0

- 1.x: features in minors, fixes in patches, no breaking change to the public API; deprecations
  warn once and are removed no earlier than 2.0.
- 2.0: the renames and domain split in `docs/lunibee-2-architecture.md` (`GuildResource`,
  `GuildService`, `Store`, `Fleet`…), and anything deprecated during 1.x.

## Release checklist

- [ ] Root and workspace package versions correct (1.0.0)
- [ ] Changelog and upgrade guide updated
- [ ] P0/P1 resolved and verified; P2/P3 resolved or tracked
- [ ] `check:deps`, API audit, prettier, typecheck, tests + coverage, `check:leaks`
- [ ] Production build, DTS build, docs build, generated API docs
- [ ] Previous release archived in the docs version picker
- [ ] Final smoke test: `bunx lunibee init` → run → commands answer; voice smoke test passes

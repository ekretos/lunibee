`CreateButton` creates Discord button components for use inside `CreateActionRow`.

## Import

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { CreateButton, ButtonType } from "lunibee";
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    import { CreateButton, ButtonType } from "lunibee";
    ```
  </TabItem>
</Tabs>

## Methods

All methods return `this` for chaining.

### `setCustomId(id)`

Sets the custom ID for interactive buttons (required for non-link buttons).

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    button.setCustomId("confirm_action");
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    button.setCustomId("confirm_action");
    ```
  </TabItem>
</Tabs>

### `setLabel(label)`

Sets the button label text (max 80 characters).

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    button.setLabel("Confirm");
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    button.setLabel("Confirm");
    ```
  </TabItem>
</Tabs>

### `setStyle(style)`

Sets the button style. Use the `ButtonType` enum:

| Constant | Value | Appearance |
|---|---|---|
| `ButtonType.Primary` | `1` | Blue |
| `ButtonType.Secondary` | `2` | Gray |
| `ButtonType.Success` | `3` | Green |
| `ButtonType.Danger` | `4` | Red |
| `ButtonType.Link` | `5` | URL link (gray, opens in browser) |

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    button.setStyle(ButtonType.Danger);
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    button.setStyle(ButtonType.Danger);
    ```
  </TabItem>
</Tabs>

### `setURL(url)`

Sets the URL for link buttons (`ButtonType.Link`). Link buttons cannot have a `customId`.

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    button.setStyle(ButtonType.Link).setURL("https://lunibee.js.org");
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    button.setStyle(ButtonType.Link).setURL("https://lunibee.js.org");
    ```
  </TabItem>
</Tabs>

### `setEmoji(emoji)`

Adds an emoji to the button.

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    button.setEmoji("🚀");
    button.setEmoji({ id: "123456789", name: "lunibee" });
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    button.setEmoji("🚀");
    button.setEmoji({ id: "123456789", name: "lunibee" });
    ```
  </TabItem>
</Tabs>

### `setDisabled(disabled?)`

Disables or enables the button.

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    button.setDisabled(true);
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    button.setDisabled(true);
    ```
  </TabItem>
</Tabs>

### `toJSON()`

Serializes to a raw Discord component object.

## Examples

**Confirmation flow with two buttons**

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { CreateActionRow, CreateButton, ButtonType } from "lunibee";

    const row = new CreateActionRow<CreateButton>().addComponents(
      new CreateButton()
        .setCustomId("confirm")
        .setLabel("Confirm")
        .setStyle(ButtonType.Success)
        .setEmoji("✅"),
      new CreateButton()
        .setCustomId("cancel")
        .setLabel("Cancel")
        .setStyle(ButtonType.Danger)
        .setEmoji("❌"),
    );

    await channel.send({ content: "Are you sure?", components: [row] });

    // Handle the button click:
    client.on("interactionCreate", async (interaction) => {
      if (!interaction.isMessageComponent()) return;
      if (interaction.customId === "confirm") {
        await interaction.update({ content: "✅ Confirmed!", components: [] });
      } else if (interaction.customId === "cancel") {
        await interaction.update({ content: "❌ Cancelled.", components: [] });
      }
    });
    ```
  </TabItem>

## Styles and Validation (0.2.0)

* `setSKUId(skuId)` makes a premium (purchase) button.
* `setStyle()` drops fields the new style cannot carry: link buttons have a
  URL and no custom ID or SKU; premium buttons have only a SKU; other styles
  have a custom ID and no URL or SKU.
* `toJSON()` throws when required fields are missing (custom ID, URL or SKU
  for the style; a label or emoji for non-premium buttons) or when fields that
  the style forbids are set.

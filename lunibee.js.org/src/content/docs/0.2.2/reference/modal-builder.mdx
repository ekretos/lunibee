`CreateModal` creates a modal popup form that Discord displays to a user. Modals can contain 1–5 `CreateActionRow<CreateTextInput>` rows.

## Import

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { CreateModal, CreateActionRow, CreateTextInput, TextInputType } from "lunibee";
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    import { CreateModal, CreateActionRow, CreateTextInput, TextInputType } from "lunibee";
    ```
  </TabItem>
</Tabs>

## Methods

### `setCustomId(id)`

Sets the custom ID used to identify this modal when submitted (max 100 characters).

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    modal.setCustomId("ticket_modal");
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    modal.setCustomId("ticket_modal");
    ```
  </TabItem>
</Tabs>

### `setTitle(title)`

Sets the modal window title (max 45 characters).

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    modal.setTitle("Open a Support Ticket");
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    modal.setTitle("Open a Support Ticket");
    ```
  </TabItem>
</Tabs>

### `addComponents(...rows)`

Adds `CreateActionRow<CreateTextInput>` rows to the modal (1–5).

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    modal.addComponents(
      new CreateActionRow<CreateTextInput>().addComponents(
        new CreateTextInput()
          .setCustomId("subject")
          .setLabel("Subject")
          .setStyle(TextInputType.Short)
          .setRequired(true),
      ),
    );
    ```
  </TabItem>

  <TabItem label="JavaScript">
    ```js
    modal.addComponents(
      new CreateActionRow().addComponents(
        new CreateTextInput()
          .setCustomId("subject")
          .setLabel("Subject")
          .setStyle(TextInputType.Short)
          .setRequired(true),
      ),
    );
    ```
  </TabItem>
</Tabs>

### `toJSON()`

Serializes to a raw Discord API-compatible modal object.

***

## `CreateTextInput`

### Methods

| Method | Description |
|---|---|
| `setCustomId(id)` | Unique ID for this field (used in `getRequiredInputValue()`). |
| `setLabel(label)` | The visible field label (max 45 chars). |
| `setStyle(style)` | `TextInputType.Short` (single line) or `TextInputType.Paragraph` (multi-line). |
| `setRequired(required)` | Whether the field is required. |
| `setValue(value)` | Pre-filled default value. |
| `setPlaceholder(text)` | Placeholder text (max 100 chars). |
| `setMinLength(min)` | Minimum character length. |
| `setMaxLength(max)` | Maximum character length. |

## Full Example

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import {
      CreateModal,
      CreateActionRow,
      CreateTextInput,
      TextInputType,
    } from "lunibee";

    // Build the modal
    const modal = new CreateModal()
      .setCustomId("report_form")
      .setTitle("Report a User")
      .addComponents(
        new CreateActionRow<CreateTextInput>().addComponents(
          new CreateTextInput()
            .setCustomId("reported_user")
            .setLabel("Reported User ID or Username")
            .setStyle(TextInputType.Short)
            .setRequired(true),
        ),
        new CreateActionRow<CreateTextInput>().addComponents(
          new CreateTextInput()
            .setCustomId("reason")
            .setLabel("Reason for reporting")
            .setStyle(TextInputType.Paragraph)
            .setRequired(true)
            .setMaxLength(1000),
        ),
      );

    // Show the modal in response to a command
    client.on("interactionCreate", async (interaction) => {
      if (!interaction.isChatInputCommand() || interaction.commandName !== "report") return;
      await interaction.showModal(modal);
    });

    // Handle the modal submission
    client.on("interactionCreate", async (interaction) => {
      if (!interaction.isModalSubmit() || interaction.customId !== "report_form") return;
      const userId = interaction.getRequiredInputValue("reported_user");
      const reason = interaction.getRequiredInputValue("reason");
      await interaction.reply({
        content: `📨 Report filed for **${userId}**: ${reason}`,
        ephemeral: true,
      });
    });
    ```
  </TabItem>

## 0.2.1 Additions

### `addTextInputs(...inputs)`

Adds text inputs, each in its own action row (the layout Discord requires), so you do not build the rows yourself. A modal holds at most five.

```ts
new CreateModal()
  .setCustomId("feedback")
  .setTitle("Feedback")
  .addTextInputs(
    new CreateTextInput().setCustomId("title").setLabel("Subject").setStyle(TextInputType.Short),
    new CreateTextInput().setCustomId("body").setLabel("Details").setStyle(TextInputType.Paragraph),
  );
```

`toJSON()` is now typed with a required `custom_id` and `title`, matching what it validates.

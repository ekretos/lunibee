`lunibee` (voice) tracks voice sessions and moves audio through a player and receiver.
It is transport-agnostic: it does not open the voice WebSocket or UDP socket, encrypt
packets or run a voice heartbeat. You attach transports that do that, and Lunibee handles
lifecycle, speaking state and audio routing.

## Joining a channel

`joinVoiceChannel` keeps one connection per guild: calling it again moves the existing
connection instead of creating a second one.

<Tabs>
<TabItem label="TypeScript">
```ts
import {
  joinVoiceChannel,
  getVoiceConnection,
  entersState,
  VoiceConnectionState,
} from "lunibee";

const connection = joinVoiceChannel({
  guildId: "123456789012345678",
  channelId: "987654321098765432",
  selfDeaf: true,
});
connection.attachTransports(myVoiceGatewayTransport, myUdpTransport);
await entersState(connection, VoiceConnectionState.Connected, 5_000);

getVoiceConnection("123456789012345678") === connection; // true
```
</TabItem>
<TabItem label="JavaScript">

You can also construct `new VoiceConnection({ guildId, channelId, selfMute, selfDeaf })`
directly and call `connect()`.

## Lifecycle

States are `disconnected`, `connecting`, `connected` and `destroyed`
(`VoiceConnectionState`, alias `VoiceConnectionStatus`).

<Tabs>
<TabItem label="TypeScript">
```ts
// VoiceConnection passes the NEW state first.
connection.on("stateChange", (newState, oldState) => {
  console.log(`Voice: ${oldState} → ${newState}`);
});
connection.on("error", (error) => console.error(error));
```
</TabItem>
<TabItem label="JavaScript">
```js
// VoiceConnection passes the NEW state first.
connection.on("stateChange", (newState, oldState) => {
  console.log(`Voice: ${oldState} → ${newState}`);
});
connection.on("error", (error) => console.error(error));
```
</TabItem>
</Tabs>

## Playing audio

`AudioPlayer` reads an `AudioStream` and passes each chunk to `onChunk()`. Override it to
send audio to your UDP transport. `AudioPlayer`'s `stateChange` passes the **old** state
first: `(from, to)`.

<Tabs>
<TabItem label="TypeScript">
```ts
import { AudioPlayer, createAudioResource, SpeakingFlags } from "lunibee";

class UdpPlayer extends AudioPlayer {
  protected override onChunk(chunk: Uint8Array): void {
    myUdpTransport.send(chunk, host, port);
  }
}

const player = new UdpPlayer();
connection.setSpeaking(SpeakingFlags.Microphone);
await player.play(createAudioResource(opusStream, { title: "Track" }));
player.on("finish", () => connection.setSpeaking(0));
```
</TabItem>
<TabItem label="JavaScript">

## Receiving audio

Feed incoming UDP packets to `connection.receiver.onPacket(packet)`, map SSRCs to users
with `mapSsrc(ssrc, userId)`, then `subscribe(userId)` for that user's `AudioStream`.

See the [VoiceConnection & AudioPlayer reference](/reference/voice-connection/) for
every method.

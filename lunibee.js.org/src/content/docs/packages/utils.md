# `@lunibee/utils`

`@lunibee/utils` provides shared runtime helpers across Lunibee packages.

## Installation

```bash
bun add @lunibee/utils
```

## Features

- Snowflake validation (`isSnowflake`, `extractTimestamp`).
- Fast shallow/deep cloning.
- Constant-time string matching.

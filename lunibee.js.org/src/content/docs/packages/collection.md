# `@lunibee/collection`

`@lunibee/collection` is a high-speed in-memory cache data structure.

## Installation

```bash
bun add @lunibee/collection
```

## Features

- Configurable max-size boundaries (LRU eviction).
- Time-To-Live (TTL) entry expiration.
- Custom predicate invalidation.

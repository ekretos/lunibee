# `@lunibee/builders`

`@lunibee/builders` provides compile-time and runtime validated builders for Discord UI components.

## Installation

```bash
bun add @lunibee/builders
```

## Available Builders

- `EmbedBuilder`
- `ButtonBuilder`
- `ActionRowBuilder`
- `StringSelectBuilder`
- `EntitySelectBuilder`
- `ModalBuilder`
- `TextInputBuilder`

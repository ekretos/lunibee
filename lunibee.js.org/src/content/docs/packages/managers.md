# `@lunibee/managers`

`@lunibee/managers` manages resource caching and REST mutations for channels, guilds, users, and messages.

## Installation

```bash
bun add @lunibee/managers
```

## Available Managers

- `UserManager`
- `GuildManager`
- `ChannelManager`
- `MessageManager`
- `ThreadManager`

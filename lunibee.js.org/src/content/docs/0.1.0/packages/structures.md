# `@lunibee/structures`

`@lunibee/structures` provides rich TypeScript representations of Discord API entities.

## Installation

```bash
bun add @lunibee/structures
```

## Available Structures

* `User`, `Guild`, `GuildMember`
* `Channel`, `TextChannel`, `VoiceChannel`, `ThreadChannel`
* `Message`
* `Interaction`, `ChatInputCommandInteraction`, `ButtonInteraction`

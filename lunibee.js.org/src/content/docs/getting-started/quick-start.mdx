Let's build a small, useful Discord bot with Lunibee and Bun.

## 1. Create the project

```bash
mkdir my-bot
cd my-bot
bun init
bun add lunibee
```

## 2. Add your token

Create a `.env` file:

```sh
DISCORD_TOKEN="your-bot-token-here"
```

Never commit your real bot token to Git.

## 3. Create `src/index.ts`

```ts
import { Client, IntentBits, command, option } from "lunibee";

const bot = new Client({
  token: process.env.DISCORD_TOKEN!,
  intents: [IntentBits.guilds, IntentBits.guildMessages, IntentBits.messageContent],
});

// One definition: runs as /ping and as !ping.
bot.commands.add(
  command({
    name: "ping",
    description: "Check that the bot is alive",
    prefix: true,
    async run({ reply }) {
      await reply("Pong! 🏓");
    },
  }),
  command({
    name: "kick",
    description: "Kick a member",
    permissions: ["KickMembers"],
    prefix: true,
    options: {
      user: option.user({ required: true }),
      reason: option.string({ max: 500 }),
    },
    async run({ bot, options, guildId, reply }) {
      // options.user is an id, options.reason is string | undefined
      await bot.member(guildId!, options.user).kick(options.reason);
      await reply(`Kicked <@${options.user}>.`);
    },
  }),
);

bot.once("ready", async (user) => {
  console.log(`🐝 Logged in as ${user.username} (${user.id})`);
  await bot.commands.deploy();
});
bot.commands.listen({ prefix: "!" });

await bot.login();
```

`prefix: true` needs the `MessageContent` intent; Lunibee warns at startup when it is missing.

## 4. Run it

```bash
bun run src/index.ts
```

During development:

```bash
bun --watch src/index.ts
```

Send `!ping` or run `/ping` in a server the bot is in.

## What next?

Once the bot is running, these are the most useful next steps:

As the bot grows, scaffold one file per command, event handler and component with the
[CLI](/packages/cli/): `bunx lunibee create command ping --both`, then call
`registerCommands(bot)` from the generated `src/commands/index.ts`.

Reach Discord by ids, with one rule for every read: `peek()` is the cache, `get()` is the cache
then Discord, `fetch()` is Discord.

```ts
const member = await bot.member(guildId, userId).get();
await bot.member(guildId, userId).timeout("10m", "spam");
await bot.channel(channelId).send("Hello!");

const channel = await bot.channel(channelId).get();
if (channel.is("text")) await channel.send("Typed as a text channel.");

await bot.api.guilds(guildId).members(userId).patch({ nick: "x" }, { reason: "rename" });
```

See [Handles](/reference/handles/), [Commands](/reference/commands/) and [bot.api](/reference/api/).

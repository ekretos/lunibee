## Button & Action Row Builders

<Tabs>
  <TabItem label="TypeScript">
    ```ts
    import { CreateActionRow, CreateButton, ButtonType } from "lunibee";
    const primaryBtn = new CreateButton()
      .setCustomId("primary_action")
      .setLabel("Click Me!")
      .setStyle(ButtonType.Primary)
      .setEmoji("🚀");
    const linkBtn = new CreateButton()
      .setLabel("Documentation")
      .setStyle(ButtonType.Link)
      .setURL("https://github.com/Ekretos/lunibee");
    const row = new CreateActionRow().addComponents(primaryBtn, linkBtn);
    await channel.send({
      content: "Choose an option:",
      components: [row],
    });
    ```
  </TabItem>

## Entity Select Menus

For user, role, mentionable and channel pickers, use the fixed-type builders (or
`CreateEntitySelect` with a component type). `CreateStringSelectMenu` is an alias of
`CreateStringSelect`.

```ts
import {
  CreateUserSelectMenu,
  CreateRoleSelectMenu,
  CreateChannelSelectMenu,
  CreateMentionableSelectMenu,
} from "lunibee";

const pickUser = new CreateUserSelectMenu().setCustomId("pick_user");
```

## Context Menu Commands

```ts
import { CreateContextMenuCommand, CreateUserCommand, CreateMessageCommand } from "lunibee";

new CreateContextMenuCommand().setName("Report").setType(3); // 2 = USER, 3 = MESSAGE
new CreateUserCommand().setName("View Profile");             // type 2
new CreateMessageCommand().setName("Quote");                  // type 3
```

## Validation on Serialization

`toJSON()` checks a component as a whole, so mistakes fail locally instead of
as a Discord 400: buttons need a custom ID (a URL for links, a SKU for premium
buttons via `setSKUId()`) and a label or emoji; selects need a custom ID and
`min_values <= max_values`; a select or text input must be alone in its action
row; modals need a custom ID, title and at least one component.

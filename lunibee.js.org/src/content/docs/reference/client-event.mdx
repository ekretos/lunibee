import { Tabs, TabItem } from '@astrojs/starlight/components';

`ClientEvent` is a string enum of all events the `Client` emits. Use it with `client.on(ClientEvent.MessageCreate, ...)` for type-safe event subscriptions instead of string literals.

## Import

<Tabs>
<TabItem label="TypeScript">
```ts
import { ClientEvent } from "lunibee";
```
</TabItem>
<TabItem label="JavaScript">
```js
import { ClientEvent } from "lunibee";
```
</TabItem>
</Tabs>

## Usage

<Tabs>
<TabItem label="TypeScript">
```ts
client.on(ClientEvent.Ready, (user) => {
  console.log(`🐝 Logged in as ${user.username}`);
});

// Equivalent string form (also valid):
client.on("ready", (user) => { ... });
```
</TabItem>
<TabItem label="JavaScript">
```js
client.on(ClientEvent.Ready, (user) => {
  console.log(`🐝 Logged in as ${user.username}`);
});

// Equivalent string form (also valid):
client.on("ready", (user) => { ... });
```
</TabItem>
</Tabs>

## Event Reference

### Lifecycle

| Event | String Key | Listener Args |
|---|---|---|
| `ClientEvent.Ready` | `"ready"` | `(user: ClientUser)` |
| `ClientEvent.Resumed` | `"resumed"` | `()` |
| `ClientEvent.InvalidSession` | `"invalidSession"` | `(isRecoverable: boolean)` |
| `ClientEvent.Open` | `"open"` | `()` |
| `ClientEvent.Close` | `"close"` | `({ code: number, action: string })` |
| `ClientEvent.Error` | `"error"` | `(error: Error)` |
| `ClientEvent.Raw` | `"raw"` | `({ event: string, data: unknown })` |

### Messages

| Event | String Key | Listener Args |
|---|---|---|
| `ClientEvent.MessageCreate` | `"messageCreate"` | `(message: Message)` |
| `ClientEvent.MessageUpdate` | `"messageUpdate"` | `(message: Message)` |
| `ClientEvent.MessageDelete` | `"messageDelete"` | `(data: APIMessageDeleteEvent)` |
| `ClientEvent.MessageDeleteBulk` | `"messageDeleteBulk"` | `(data: APIMessageDeleteBulkEvent)` |

### Scheduled Events, AutoMod, Invites, Webhooks, Polls

| Event | Description |
|---|---|
| `GuildScheduledEventCreate/Update/Delete` | Guild scheduled event lifecycle. |
| `AutoModerationRuleCreate/Update/Delete` | AutoMod rule changes. |
| `AutoModerationActionExecution` | AutoMod action fired. |
| `InviteCreate` / `InviteDelete` | Invite creation/deletion. |
| `WebhooksUpdate` | Webhook updates. |
| `MessagePollVoteAdd` / `MessagePollVoteRemove` | Poll vote events. |

## Examples

**Handle errors gracefully**

<Tabs>
<TabItem label="TypeScript">
```ts
client.on(ClientEvent.Error, (error) => {
  console.error("Client error:", error.message);
});
```
</TabItem>
<TabItem label="JavaScript">
```js
client.on(ClientEvent.Error, (error) => {
  console.error("Client error:", error.message);
});
```
</TabItem>
</Tabs>

**React to every message (read-only monitor)**

<Tabs>
<TabItem label="TypeScript">
```ts
client.on(ClientEvent.MessageCreate, (message) => {
  if (!message.author.bot) {
    console.log(`[${message.guildId ?? "DM"}] ${message.author.username}: ${message.content}`);
  }
});
```
</TabItem>
<TabItem label="JavaScript">
```js
client.on(ClientEvent.MessageCreate, (message) => {
  if (!message.author.bot) {
    console.log(`[${message.guildId ?? "DM"}] ${message.author.username}: ${message.content}`);
  }
});
```
</TabItem>
</Tabs>

**Log raw Gateway events**

<Tabs>
<TabItem label="TypeScript">
```ts
client.on(ClientEvent.Raw, ({ event, data }) => {
  if (event === "VOICE_STATE_UPDATE") {
    console.log("Voice state:", data);
  }
});
```
</TabItem>
<TabItem label="JavaScript">
```js

    console.log("Voice state:", data);
  }

```
</TabItem>
</Tabs>

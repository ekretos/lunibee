Lunibee exports two intent constant objects to accommodate different coding styles. Both resolve to the same bitfield values.

## Import

<Tabs>
<TabItem label="TypeScript">
```ts
import { IntentBits, GatewayIntentBits, Intents } from "lunibee";
```
</TabItem>
<TabItem label="JavaScript">
```js
import { IntentBits, GatewayIntentBits, Intents } from "lunibee";
```
</TabItem>
</Tabs>

- **`IntentBits`** — idiomatic camelCase keys (e.g. `IntentBits.guilds`)
- **`GatewayIntentBits`** — Discord-standard PascalCase keys (e.g. `GatewayIntentBits.Guilds`)
- **`Intents`** — alias for `IntentBits`

## Usage Styles

### Array form (recommended with `IntentBits`)

<Tabs>
<TabItem label="TypeScript">
```ts
import { Client, IntentBits } from "lunibee";

const client = new Client({
  token: process.env.DISCORD_TOKEN!,
  intents: [
    IntentBits.guilds,
    IntentBits.guildMessages,
    IntentBits.messageContent,
  ],
});
```
</TabItem>
<TabItem label="JavaScript">
```js
import { Client, IntentBits } from "lunibee";

const client = new Client({
  token: process.env.DISCORD_TOKEN,
  intents: [
    IntentBits.guilds,
    IntentBits.guildMessages,
    IntentBits.messageContent,
  ],
});
```
</TabItem>
</Tabs>

### Bitwise OR form (works with either)

<Tabs>
<TabItem label="TypeScript">
```ts
import { Client, GatewayIntentBits } from "lunibee";

const client = new Client({
  token: process.env.DISCORD_TOKEN!,
  intents:
    GatewayIntentBits.Guilds |
    GatewayIntentBits.GuildMessages |
    GatewayIntentBits.MessageContent,
});
```
</TabItem>
<TabItem label="JavaScript">
```js
import { Client, GatewayIntentBits } from "lunibee";

const client = new Client({
  token: process.env.DISCORD_TOKEN,
  intents:
    GatewayIntentBits.Guilds |
    GatewayIntentBits.GuildMessages |
    GatewayIntentBits.MessageContent,
});
```
</TabItem>
</Tabs>

## Privileged Intents

> [!IMPORTANT]
> **`GuildMembers`**, **`GuildPresences`**, and **`MessageContent`** are **privileged intents**.
> You must enable them in the [Discord Developer Portal](https://discord.com/developers/applications) under **Bot → Privileged Gateway Intents** before your bot can use them.

## `resolveGatewayIntents`

A utility function that converts any `GatewayIntentResolvable` to a raw integer bitfield:

<Tabs>
<TabItem label="TypeScript">
```ts
import { resolveGatewayIntents, IntentBits } from "lunibee";

const bits = resolveGatewayIntents([IntentBits.guilds, IntentBits.guildMessages]);
// → 513 (1 | 512)
```
</TabItem>
<TabItem label="JavaScript">
```js
import { resolveGatewayIntents, IntentBits } from "lunibee";

const bits = resolveGatewayIntents([IntentBits.guilds, IntentBits.guildMessages]);
// → 513 (1 | 512)
```
</TabItem>
</Tabs>

Accepts:
- A number: returned as-is.
- A string key from either intent object (e.g. `"Guilds"`, `"guilds"`).
- An array of any of the above.

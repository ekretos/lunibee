## Kinds (0.3.0)

Every channel has a `kind`, a short name in place of the numeric `type`:

| `kind` | `type` | Class |
|---|---|---|
| `"text"` | 0 | `TextChannel` |
| `"dm"`, `"group-dm"` | 1, 3 | `DMChannel` |
| `"voice"` | 2 | `VoiceChannel` |
| `"category"` | 4 | `CategoryChannel` |
| `"announcement"` | 5 | `NewsChannel` |
| `"thread"` | 10, 11, 12 | `ThreadChannel` |
| `"stage"` | 13 | `StageChannel` |
| `"directory"` | 14 | `Channel` |
| `"forum"` | 15 | `ForumChannel` |
| `"media"` | 16 | `MediaChannel` |
| `"unknown"` | anything else | `Channel` |

`channel.is(...kinds)` tells you whether it is one of them and narrows the type; `channel.as(...kinds)` returns it typed that way, or throws a `TypeError` that names both kinds.

```ts
const channel = await bot.channel(id).get();
if (channel.is("text", "announcement")) await channel.send("hi");   // TextChannel | NewsChannel

const voice = await bot.channel(id).as("voice");                      // VoiceChannel, or a clear error
switch (channel.kind) {
  case "forum": case "media": /* … */ break;
}
```

`channelKindOf(type)` and `channelTypesOf(kind)` convert between the two, and `ChannelEnum` still holds the raw numbers that appear in payloads.

## Properties

| Property | Type | Description |
|---|---|---|
| `id` | `string` | Snowflake ID. |
| `type` | `number` | Channel type (see `ChannelEnum`). |
| `name` | `string \| null \| undefined` | Channel name. |
| `guildId` | `string \| undefined` | Guild this channel belongs to. |
| `topic` | `string \| null \| undefined` | Channel topic. |
| `parentId` | `string \| null \| undefined` | Parent category ID. |
| `nsfw` | `boolean \| undefined` | Whether the channel is age-restricted. |
| `rateLimitPerUser` | `number \| undefined` | Slowmode in seconds. |
| `position` | `number \| undefined` | Sorting position. |
| `createdAt` | `Date` | Timestamp derived from the snowflake. |

## Methods

### `send(options)`

Sends a message to this channel.

<Tabs>
<TabItem label="TypeScript">
```ts
const msg = await channel.send({ content: "Hello! 🐝" });

// With embeds and components:
await channel.send({
  embeds: [embed],
  components: [row],
});
```
</TabItem>
<TabItem label="JavaScript">
```js
const msg = await channel.send({ content: "Hello 🐝" });

// With embeds and components:
await channel.send({
  embeds: [embed],
  components: [row],
});
```
</TabItem>
</Tabs>


`sendMessage(options)` is a deprecated alias of `send()`, removed in 0.3.0.

### `editTopic(topic)`

Changes only the channel topic. Pass `null` to clear it.

<Tabs>
<TabItem label="TypeScript">
```ts
await channel.editTopic("Community announcements and updates.");
await channel.editTopic(null); // clears topic
```
</TabItem>
<TabItem label="JavaScript">
```js
await channel.editTopic("Community announcements and updates.");
await channel.editTopic(null); // clears topic
```
</TabItem>
</Tabs>

### `editParent(parentId)`

Moves the channel to a different category. Pass `null` to remove the parent.

<Tabs>
<TabItem label="TypeScript">
```ts
await channel.editParent(categoryId);
await channel.editParent(null);
```
</TabItem>
<TabItem label="JavaScript">
```js
await channel.editParent(categoryId);
await channel.editParent(null);
```
</TabItem>
</Tabs>

### `delete(reason?)`

Deletes this channel. `reason` is shown in the audit log.

<Tabs>
<TabItem label="TypeScript">

</TabItem>
<TabItem label="JavaScript">
```js

```
</TabItem>
</Tabs>

### `toString()`

Returns the Discord channel mention string. Automatically used in template literals.

<Tabs>
<TabItem label="TypeScript">

</TabItem>

</TabItem>

## Examples

**Create a support ticket channel**

<Tabs>
<TabItem label="TypeScript">
```ts
client.on("interactionCreate", async (interaction) => {
  if (!interaction.isChatInputCommand() || interaction.commandName !== "ticket") return;

  const guild = client.guilds.get(interaction.guildId!);
  const channel = await client.channels.create(interaction.guildId!, {
    name: `ticket-${interaction.user.id}`,
    topic: `Support ticket for ${interaction.user.username}`,
    parent_id: TICKET_CATEGORY_ID,
  });

  await channel.send({
    content: `Welcome ${interaction.user}! Support will be with you shortly.`,
  });
  await interaction.reply({ content: `Ticket created: ${channel}`, ephemeral: true });
});
```
</TabItem>

**Rename a channel from a command**

<Tabs>
<TabItem label="TypeScript">
```ts
client.on("interactionCreate", async (interaction) => {
  if (!interaction.isChatInputCommand() || interaction.commandName !== "rename") return;
  const name = interaction.options.getString("name", true);
  const channel = client.channels.get(interaction.channelId);
  if (!channel) return interaction.reply({ content: "Channel not found.", ephemeral: true });
  await channel.editName(name);
  await interaction.reply({ content: `✅ Renamed to **${name}**` });
});
```
</TabItem>

## 0.2.1 Additions

### `editPermissionOverwrite(targetId, changes, options?)`

Changes some permissions of one role's or member's overwrite and keeps the rest (unlike `permissionOverwrites(id).edit()`, which replaces the whole overwrite). `true` allows, `false` denies, `null` resets to inherited. Pass `type` (`0` role, `1` member) when the overwrite does not exist yet.

```ts
await channel.editPermissionOverwrite(userId, { ViewChannel: true, SendMessages: false }, { type: 1, reason: "Ticket locked" });
```

The manager form is `client.channels.permissionOverwrites(channelId).update(id, { allow?, deny?, inherit? }, { type?, reason? })` with bitfields. It reads the cached overwrites and fetches the channel when they are unknown.

`send` also accepts `files` (see [Message](/reference/message/)).
